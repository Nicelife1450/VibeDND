# VibeDND 两阶段缺陷检测路线(2026-08 定稿)

> 本文档是当前唯一的任务路线权威来源。历史实验细节见 `experiments/log.md` 与 `experiments/final_report.md`。

## 背景与结论回顾

- 任务: 配网无人机巡检缺陷检测, yolo11n, 16 类, 冻结 val(`dataset/split_reduced.json`, 733 张), 目标 mAP50 ≥ 0.40
- 2026-07 七轮实验(R1-R7)结论: 单模型直接检测封顶 mAP50=0.088(TTA 0.096); **瓶颈 = 属性级缺陷(锈蚀/污秽/破损)视觉显著性低 + 自有标注质量差(松散 ROI + 漏标)**
- R8-prep 关键对照: 同管线 yolo11n 在 InsPLAD(高质量紧框部件数据)上 mAP50=**0.916** → 管线无罪, 数据是全部问题
- 绝缘子特写跨域验证: InsPLAD 模型以 0.81 置信度认出中国配网绝缘子 → **部件级特征跨域通用**

## 核心决策

1. **自有标注全部废弃**(2026-08-12 用户确认: 连验收 GT 也不要; 文件已移至 `experiments/archive/annotations/`)。注意: `巡检报告/` 原始目录本机已不存在, annotations.json 不可再生
2. **输电侧外部数据全部废弃**(2026-08-12 用户确认): 公开"缺陷标注"数据 100% 是输电绝缘子(InsPLAD/Tomaszewski/CPLID/ID-2024 实测归属核实后均已删除); 只保留配网数据(缺陷或部件标注皆可)
3. **两阶段混合 pipeline**(见下), 替代单模型直接缺陷检测
4. **外部数据现状**(2026-08-12 收缩后): 仅剩 ICARUS(中压配电杆顶, 单类部件) + EPRI 标签 CSV(无图); "配网+缺陷标注"数据集公开不存在, 缺陷类外部料归零 → 缺陷监督只能来自自有数据(合成/人工)或跨域迁移

## ⚠️ 验收协议待重定义

旧口径(16 类冻结 val mAP50 ≥ 0.40)随 GT 废弃而失效。新 pipeline 的验收需要在以下方案中择一(待用户决定):
- A. 未来人工重标一批高质量测试集(推荐, 数量可小, 如 200-300 张紧框)
- B. 用公开数据集(如 EPRI 配电)的 held-out 集做跨域基准, 只证能力不证业务指标
- C. 业务指标改为巡检报告级核对(检出缺陷 vs 报告条目的一致性, 无需框级 GT)

## 16 类缺陷的二分本质

| 类型 | 类别 | 处理方式 |
|---|---|---|
| 部件状态型(11 类) | 绝缘子污秽/破损/固定不牢, 横担锈蚀, 套管/避雷器破损, 绝缘罩脱落, 绝缘护套缺陷, 绝缘线绝缘层破损, 绑扎线不规范, 接地引下线连接不良 | **级联**: 部件检测 → 状态分类 |
| 场景异物型(5 类) | 距树木距离不够, 杆塔异物鸟巢, 杆基杂物堆积, 其他缺陷, 杆塔未设防护设施 | **直接检测**分支(异物本身是目标;"未设防护设施"是缺失检测, 最难, 单独讨论) |

## Pipeline 总览

```
预训练集(公开数据, ~5 万张):
  主干部件级:  EPRI 配电巡检 29.6k(配电域!, 像素级→紧框) + InsPLAD 10.6k(已有)
  故障诊断级:  UPID 6.9k + EPRI IDID 1.7k + ID-2024 1.6k(缺陷框)
  状态分类料:  InsPLAD-fault(图像级标签, 第二阶段用)
        │
        ▼
分支 A(部件状态型 11 类):
  Stage 1 部件检测器(yolo11n): 预训练 → 适配中国配网广角场景
     ⚠️ 自有数据无部件标注 → 部件标签从缺陷类名反推 或 外部零样本迁移
  Stage 2 状态分类器(轻量 CNN): 部件裁剪图 → 正常/锈蚀/污秽/破损...
     训练料: InsPLAD-fault + UPID/IDID 缺陷框裁剪 (+ 可选: 自有 ROI 裁剪, 需质检)
        │
分支 B(场景异物型 5 类):
  直接检测(基于预训练 backbone 微调, 或沿用 R3 冠军的强项类)
        │
        ▼
汇合输出缺陷框 → 验收(协议待重定义, 见上节; 历史基线 0.088)
```
