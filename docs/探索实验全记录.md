# VibeDND 探索实验全记录(2026-07 → 2026-08)

> 本文档按"数据来源路线"的演进整理全部探索实验:**原标注训练 → 原标注+弱监督改造 → 开源数据迁移 → Agent 重新标注**。
> 细节数据见 `experiments/log.md`(逐轮日志)与 `experiments/final_report.md`(R1-R7 终版报告);当前路线权威文档是 `docs/两阶段路线.md`。

## 任务背景

- 数据: 3,665 张配网无人机巡检图(主力 4864×3648 / 4000×3000),72 个原始缺陷类归并为 16 类
- 模型约束: yolo11n;原验收口径: 冻结 val(733 张)mAP50 ≥ 0.40
- 16 类缺陷的二分本质(后验总结,决定了后来的路线):
  - **部件状态型 11 类**(绝缘子污秽/破损/固定不牢、横担锈蚀、套管/避雷器破损、绝缘罩脱落、绝缘护套缺陷、绝缘线绝缘层破损、绑扎线不规范、接地引下线连接不良)— 属性级缺陷,视觉显著性低
  - **场景异物型 5 类**(距树木距离不够、杆塔异物鸟巢、杆基杂物堆积、其他缺陷、杆塔未设防护设施)— 目标大,特征明确

## 阶段一:用原标注训练(2026-07, R1–R3)

原标注 = 巡检报告红圈自动提取的松散 ROI(3665 图 / 6218 框 / 16 类)。

| 轮次 | 内容 | 结果 |
|---|---|---|
| R1 | 基线(切片/整图/容量三组并行) | mAP50 0.136,但发现**数据污染**: 59.7% 图像残留报告红圈,`其他缺陷` 类 169/171 污染,模型学到"红圈→类别"捷径(AP 0.79 虚高)。作废 |
| R2 | HSV+Telea 清洗 v1 后重训 | 0.133,与 R1 持平 → 暴露清洗不彻底(轮廓版 mask 把细环判成实心圆盘)。作废 |
| R3 | 修复 mask(连通域真实面积+extent<0.4)后彻底清洗重训 | **mAP50 = 0.088(TTA 0.096)— 真实基线,旧路线交付模型** `runs/detect/r3_yolo11n_full/` |

**阶段结论**:清洗后指标不升反降,证明 R1/R2 的"学习信号"几乎全部来自红圈捷径。真实瓶颈 = 标注形态(松散 ROI)+ 缺陷视觉显著性低,不是模型容量(yolo11m 同样起不来)。per-class 可学性: 鸟巢 0.14 > 避雷器破损 0.10 > 横担锈蚀 0.09,其余 12 类 <0.05 —— **场景异物型明显比部件状态型可学**,这一观察直接催生了后来的两阶段路线。

## 阶段二:原标注 + 弱监督改造(2026-07, R4–R7)

围绕"标注能不能救"做了三轮独立验证,**全部否定**:

| 轮次 | 杠杆 | best mAP50 | 结论 |
|---|---|---|---|
| R4 | YOLO-World(yolov8x-worldv2)在 ROI 内生成设备紧框,重建数据集 | 0.019 | 低置信下紧框噪声大,紧框/松散 ROI 语义混杂,负收益 |
| R5 | 长训 500ep / 高分辨率 1920 | 0.080 | 过拟合;发现**尺度锁定**(1280 训练的模型 2560 推理仅 0.013) |
| R6 | 教师补全(自训练伪标签 +9,471 条)+ copy-paste 弱类 | 0.058 | 教师噪声稀释人工标注,负收益 |
| R7 | SAM(sam2_l)框提示无监督精修松散 ROI(61% 精修率) | 0.063(紧框口径) | 交叉对照: 松散框训练在紧框 val 上 0.068 仍更高 → **框几何不是瓶颈**,零收益 |

**阶段结论(三次独立验证一致)**: 任何"改造标注"的弱监督路线在该数据上都是负或零收益。瓶颈收紧为: 缺陷视觉显著性低 + 属性级缺陷类间语义混淆 + 标注漏标(报告只圈上报缺陷,训练信号自相矛盾)。当时结论: 唯一出路是高质量人工紧框重标注(估算 2–3 人周)。

## 阶段三:用相似开源数据集训练并迁移(2026-08, R8 → 里程碑 2–3)

### R8-prep: 决定性对照实验

同管线同模型训练 InsPLAD(高质量紧框部件数据, 10.6k 张): **mAP50 = 0.916** vs VibeDND 0.088(10 倍差距)。
→ 管线无罪,数据是全部问题的铁证。跨域测试: InsPLAD 模型以 0.81 置信度认出中国配网绝缘子特写 → **部件级特征跨域通用**,预训练迁移路线成立。

### 外部数据大搜索与收缩(2026-08-12, 用户决策)

下载/核实了全部能找到的公开电力巡检数据(UPID/ICARUS/Tomaszewski/CPLID/ID-2024/InsPLAD/EPRI/OPDL),合并过 5 源预训练集(27k 张 21 类),随后用户裁定:

- **输电侧数据全部废弃**: 所有公开"缺陷标注"数据都是输电绝缘子(InsPLAD=巴西 69–230kV,Tomaszewski=实验架摆拍,CPLID/ID-2024=中国输电铁塔),与配网场景结构差异大
- **ICARUS 杆顶废弃**(俯视视角与我方斜拍不符)
- **硬结论: 公开世界不存在"配网+缺陷标注"数据集**(Energies 2026 综述 `docs/reference.pdf` 的实测验证)

唯一留存: **EPRI 配电巡检数据**(用户表单申请获得 22 个 zip 链接,下载 8 条线路 5,678 张,9 类部件多边形标注)。

### 里程碑 3: EPRI→中国配网迁移验证通过(2026-08-13)

- `src/build_component_dataset.py`: EPRI 多边形→紧框 → `dataset/yolo_component/`(5,678 张 / 25,481 实例 / 5 类: insulator/pole/crossarm/cutout/transformer;按线路地理隔离划分 val)
- `r9_epri_component`(yolo11n, 20 轮): EPRI val **mAP50 = 0.8675**
- 跨域实测中国配网: 绝缘子迁移极好(0.5–0.8 置信),电杆良好,横担较弱(美木横担 vs 中角钢)
- `src/pseudo_label_dnd.py` 全量伪标注 3,665 张: 2,341 张(64%)有 ≥0.5 检出,7,416 实例入 `dataset/yolo_dnd_pseudo/` —— **第一批中国配网部件标签**

**阶段结论**: 部件级(Stage-1)监督问题被"EPRI 预训练 + 跨域伪标注"基本解决;缺陷状态级(Stage-2)监督仍无外部来源。

## 阶段四:用 Agent 重新标注(2026-08-14, 进行中)

### VLM(Qwen2.5-VL-7B)— 彻底证伪

- 全图部件检测: 16 张试验,与伪标注 IoU≥0.3 匹配 **0 对**,严重漏检+框松散
- 部件裁剪状态分类: **9/10 判"破损",抽看 5 张全部正常** — 在正常部件上幻觉裂纹
- 结论: 7B VLM 零样本既不能当检测器也不能当状态分类器

### Claude 视觉标注 — 部分可用,成为当前主线

| 试验 | 内容 | 结果 |
|---|---|---|
| 缺陷标注 20 张 | 16 类缺陷直标(整图判场景+裁剪判部件) | 16 条标注,抽查 high 全对;**场景异物型可用,部件状态型细微缺陷不可用**(红丹漆 vs 真锈不分、污秽不可辨) |
| 部件检测 20 张 | 7 类(绝缘子/横担/套管/避雷器/绝缘罩 + 鸟巢/杆基杂物) | **286 实例,high 占 76%**,框位抽查准确;弱项=避雷器辨识(4 例全 medium) |
| **det400 放量**(进行中) | 同 7 类 × 400 张,20 批串行子代理,断点保护协议(逐张落盘+跳过已标) | 已完成 3 批 60 张 / **926 实例**;遇 API 配额限流后改串行+断点续标 |

标注配方(已沉淀): 整图判场景 → EPRI 伪标注框引导裁剪放大判部件;保守原则(宁漏勿错、允许 0 标注、high/medium/low 置信度、notes 记漏标);判例规则迭代(带护罩套管记绝缘罩、熔断器白瓷管不标、避雷器三只一组+引线判据)。

**阶段结论**: Claude 标注可低成本解决 Stage-1 部件检测器和分支 B(场景异物型)的训练料;Stage-2 细微状态缺陷(裂纹/污秽/锈蚀分级)仍需合成或真人工,这是当前唯一未闭环的缺口。
