# 配电网 / 电力线路缺陷检测开源数据集调研报告

> 调研日期：2026-08-11
> 范围：国内外公开可获取的电力线路（含配电、输电）视觉缺陷检测数据集，以及相关的数据获取渠道。

---

## 一、总体结论

1. **严格意义上的"配电网缺陷检测"开源数据集非常少**。电网属于国家关键基础设施，出于保密要求，国内电网企业（国网、南网）的一线巡检图像基本不对外公开，学术界公开数据集以**输电线路**（尤其是绝缘子）为主。
2. 真正高质量、有学术背书、可免费下载的数据集大约有 20 个左右，主要来自 GitHub、Kaggle、IEEE DataPort、Mendeley Data、Zenodo 等学术平台。
3. 国内 CSDN、GitCode、SelectDataset 等站点上大量标注为"配网缺陷数据集"的资源**实际是付费打包售卖的二手数据**，来源和标注质量无法保证，购买前需谨慎甄别（详见第五节）。
4. 若做配电网缺陷检测研究/工程，最实用的组合是：**InsPLAD（多部件+多缺陷，规模最大）+ CPLID/IDID（绝缘子缺陷基准）+ EPRI 配电巡检图像（美国配电线路真实场景）**，必要时辅以数据增强和合成数据。

## 二、与"配电"直接相关的数据集（优先推荐）

### 1. EPRI Distribution Inspection Imagery —— 最贴近"配电网"
- **来源**：美国电力科学研究院（EPRI），美国配电线路真实无人机巡检图像
- **规模**：大规模多场景图像，含绝缘子、横担、金具等部件的缺陷标注
- **任务**：目标检测 / 缺陷分类
- **获取**：
  - Kaggle：https://www.kaggle.com/datasets/dexterlewis/epri-distribution-inspection-imagery
  - IEEE DataPort：https://ieee-dataport.org/open-access/epri-distribution-inspection-imagery
- **备注**：同源的还有 IEEE DataPort 上的 "Insulator Defect Detection" 竞赛数据（即 IDID 的来源之一）

### 2. OPDL（Overhead Power Distribution Lines）—— 15 kV 配电绝缘子
- **来源**：巴西联邦大学（UFBA），Prates 等，2019
- **规模**：4,960 张图像，4 类 15 kV 配电绝缘子（瓷针式、双色瓷、灰色聚合物、绿色玻璃），含缺陷/非缺陷（non-conformity）标签
- **任务**：绝缘子缺陷检测（图像级/区域级）
- **获取**：http://www.dee.eng.ufba.br/dslab/index.php/opdl_dataset
- **论文**：*Insulator visual non-conformity detection in overhead power distribution lines using deep learning* (Computers & Electrical Engineering, 2019)

### 3. VSB Power Line Fault Detection（Kaggle，非图像）
- **内容**：输配电线路高频电压波形信号（每样本 80 万采样点），标注局部放电（绝缘故障）
- **获取**：https://www.kaggle.com/c/vsb-power-line-fault-detection
- **备注**：适合做多模态（信号+图像）融合研究

## 三、绝缘子缺陷检测主流基准数据集

绝缘子是公开数据中资源最丰富的缺陷对象，以下数据集被学术论文广泛使用，适合做基准对比实验。

| 数据集 | 规模 | 内容 | 标注 | 获取地址 |
|---|---|---|---|---|
| **CPLID**（中国电网绝缘子数据集） | 848 张（600 正常 + 248 合成缺陷） | 无人机航拍绝缘子，缺陷样本经 TVSeg 抠图+仿射变换合成 | VOC 检测框 | https://github.com/InsulatorData/InsulatorDataSet （IEEE DataPort 同步发布） |
| **IDID**（绝缘子缺陷图像数据集） | 约 1,688–3,031 张（不同版本） | 完好 / 破损（broken）/ 闪络（flashover）三类，真实无人机巡检图 | 实例级多类标注 | Kaggle 竞赛页：https://www.kaggle.com/competitions/insulator-defect-detection/data ；镜像：https://www.kaggle.com/datasets/mazilishanglx/idid-dataset |
| **UPID**（统一绝缘子数据集） | 6,860 张 | CPLID + Insulator Dataset 合并 + Albumentations 增强 | 检测框 | https://github.com/heitorcfelix/public-insulator-datasets |
| **MPID**（合并公共绝缘子数据集，2025） | 4,807 张 / 7,850 实例 | 玻璃、瓷、复合三类绝缘子，多国多时段多天气，部分含缺陷 | YOLO 格式 | https://github.com/phd-benel/MPID （CC BY 4.0） |
| **SFID**（合成雾天绝缘子数据集） | 基于 UPID 合成 | 大气散射模型生成不同浓度雾天图像 | 检测框 | https://github.com/zhangzhengde0225/FINet |
| **Insulator-DET** | 2,150 张，640×640 | 9 类缺陷：玻璃脏污、玻璃自爆、聚合物、聚合物脏污、双伞、破盘、绝缘子、闪络、积雪 | YOLO/VOC | https://www.kaggle.com/datasets/mazilishanglx/insulator-det |
| **Junyan Wang Insulator Dataset** | DJI 无人机实拍 + 电力专家标注 | 闪络、自爆等缺陷，2024 年发布 | 检测框 | https://www.kaggle.com/datasets/jmwangdeep/junyan-wang-insulator-dataset |
| **DINS**（多样化绝缘子数据集，2024） | 大规模 | 玻璃/瓷绝缘子，单串/双串结构区分，检测 + 实例分割双任务 | 检测框 + 像素掩码 | https://github.com/beyondliberty/DINs |
| **Tomaszewski 绝缘子数据集** | 户外多光照条件 | 支柱绝缘子，含激光点辅助 | 图像级 | https://cv.po.opole.pl/dataset1 |

## 四、多部件 / 杆塔 / 导线类数据集

### 1. InsPLAD（Inspection of Power Line Assets Dataset）⭐ 综合规模最大
- **来源**：巴西，2023，真实运行线路无人机航拍
- **规模**：10,607 张高分辨率图像，17 类电力部件，28,933 个实例；其中 5 类部件带 6 种缺陷标签（4 种锈蚀、1 种破损、1 种鸟巢）
- **任务**：三合一 —— 目标检测（InsPLAD-det）+ 有监督缺陷分类 + 无监督异常检测；另有实例分割标注在 Roboflow 持续更新
- **获取**：https://github.com/andreluizbvs/InsPLAD （数据托管在 Mendeley Data / Google Drive）
- **同系列**：**STN PLAD**（133 张 5472×3648 超高分辨率图像，金具多尺度检测，适合小样本/小目标研究）https://github.com/andreluizbvs/PLAD

### 2. TTPLA（杆塔与导线实例分割）
- **规模**：1,100 张 4K（3840×2160）航拍图，8,987 个实例
- **类别**：tower-lattice / tower-tucohy / tower-wooden / cable
- **任务**：目标检测 + 实例分割（COCO 格式）
- **获取**：https://github.com/R3ab/ttpla_dataset （ACCV 2020 论文）

### 3. 其他线路类数据集

| 数据集 | 内容 | 获取 |
|---|---|---|
| **PLD-UAV** | 860 张无人机电力线图像，语义分割 | https://github.com/SnorkerHeng/PLD-UAV |
| **Yetgin PLD / GTPLD**（土耳其 TEIAS） | 8,000 张红外+可见光电力线图像（直升机拍摄），800 张带分割真值 | Mendeley Data：https://data.mendeley.com/datasets/n6wrv4ry6v 、https://data.mendeley.com/datasets/twxp8xccsw |
| **Aerial Power Infrastructure Detection**（ICARUS 项目，塞浦路斯） | 电力基础设施航拍检测 | Zenodo：https://zenodo.org/records/7781388 |
| **RSIn-dataset** | 无人机绝缘子+间隔棒检测基准 | https://github.com/caigouyihao/Rsin-dataset |
| **Power transmission line dataset**（巴西） | 输电线路路径跟踪 | IEEE DataPort（Diniz 等，2021） |

## 五、国内获取渠道及注意事项

### 免费渠道
- **百度 AI Studio**（aistudio.baidu.com）：搜索"绝缘子""电力巡检"，有不少用户上传的免费数据集，例如：
  - 高压线绝缘子数据集：https://aistudio.baidu.com/datasetdetail/122549 、/122212
  - 变压器漏油数据集：https://aistudio.baidu.com/datasetdetail/146144
- **Roboflow Universe**（universe.roboflow.com）：搜索 "insulator" "power line" "distribution"，有大量社区数据集可免费导出 VOC/YOLO/COCO 格式（如 combine_pole、power-towers、electrical_substation 等），但质量参差，需人工抽检。
- **竞赛数据**：广东电网智慧现场作业挑战赛（DataFountain）、阿里天池电力相关赛题等，数据通常**仅限竞赛使用、不允许商用**，且赛后下载渠道可能关闭，使用前务必核对许可协议。

### ⚠️ 付费数据警示
CSDN、GitCode、SelectDataset、"futureflsl2/power-industry-dataset" 等站点/仓库列出数百种"配网销钉缺失""配网绝缘子损坏""水泥电线杆缺陷"等数据集，看似针对性强，但：
1. 绝大多数需要付费（积分/私信交易），并非真正开源；
2. 图像多来自网络爬取或互相倒卖，**来源、版权、标注质量均无法验证**；
3. 部分就是上述学术公开数据集（如 CPLID）的重新打包。

如确需中文场景数据，建议优先用公开数据集训练，再通过电网企业合作或自行采集补充。

## 六、选型建议

| 研究目标 | 推荐数据集 |
|---|---|
| 配电线路部件缺陷（工程导向） | EPRI Distribution Inspection Imagery + OPDL + InsPLAD |
| 绝缘子缺陷检测基准实验（论文导向） | CPLID + IDID（经典基线），进阶用 MPID / Insulator-DET / DINS |
| 小目标 / 高分辨率金具缺陷 | STN PLAD、InsPLAD |
| 杆塔、导线检测与分割 | TTPLA、PLD-UAV、Yetgin IR/VL |
| 恶劣环境鲁棒性（雾天等） | SFID，或用 StarGAN 等做天气自适应合成 |
| 缺陷样本稀缺 | 无监督异常检测路线（InsPLAD-fault 的 anomaly detection 子集） |

### 已知局限（来自 2026 年 Energies 综述的系统分析）
- 公开数据**严重偏向绝缘子**（约占一半），导线、杆塔、小金具（销钉、防震锤、间隔棒）数据稀缺；
- 地域集中在中国、巴西、美国，存在环境偏置；
- 标注粒度多为检测框，像素级 / 故障诊断级标注很少，且命名无统一标准；
- 红外、紫外、LiDAR 等多模态数据在公开渠道几乎没有。
