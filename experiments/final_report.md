# VibeDND 缺陷检测实验终版报告

日期: 2026-07-31
任务: yolo11n 在 16 类精简数据集上冲刺 mAP50 ≥ 0.40(冻结 val)

## 最终结果(未达标, 交付最优)

| 指标 | 数值 |
|---|---|
| **交付模型** | `runs/detect/r3_yolo11n_full/weights/best.pt` |
| **mAP50(冻结 val, 733 张)** | **0.088** |

## 六轮实验全景

| 轮次 | 杠杆 | 最佳 mAP50 | 结论 |
|---|---|---|---|
| R1 | 基线(切片/整图/容量) | 0.136* | *受红圈污染虚高, 作废 |
| R2 | 红圈清洗 v1 | 0.133* | 清洗不彻底(mask 缺陷), 作废 |
| R3 | 彻底清洗后真基线 | **0.088 (TTA 0.096)** | **真实水平; 交付模型** |
| R4 | YOLO-World 紧框重标注 | 0.019 | 噪声紧框 + 语义混杂, 负收益 |
| R5 | 长训 500ep / 高分辨率 1920 | 0.080 | 过拟合; 尺度锁定 |
| R6 | 教师补全 + copy-paste | 0.058 | 弱监督噪声稀释人工标注, 负收益 |
| R7 | SAM 框提示精修(无监督) | 0.063 | 紧框训练在紧框口径下仍 < 松散框训练(0.068), 零收益 |

## 根因分析(为什么 0.40 不可达)

1. **标注形态**: 缺陷框来自巡检报告红圈检测, 是松散 ROI(含大量背景), 非设备级紧框; 标注语义本身噪声大
2. **标注不完整**: 巡检报告只圈"上报缺陷", 同图其他缺陷无标注 → 训练信号自相矛盾(教师补全试图修复, 但教师太弱, 引入的噪声大于收益)
3. **缺陷视觉显著性低**: 锈蚀/污秽/破损类是属性级差异, 4000x3000 原图上目标小且类内差异大
4. **数据规模**: 16 类 6218 条人工标注, 多数类仅数百实例

## 已证伪的杠杆(不要再试)

- 模型容量: yolo11m ≈ yolo11n(R3/R5/R6 一致)
- 训练时长: 500ep 过拟合, 峰值低于 150ep
- 高分辨率推理: 尺度锁定, 2560 反而更差
- 弱监督重标注(YOLO-World 紧框): 负收益
- 弱监督补标(教师自训练)+ copy-paste: 负收益
- 无监督精修(SAM 框提示): 零收益 — 紧框语义并不可学, 框几何不是瓶颈

## 若继续投入, 唯一有希望的路线

**人工紧框重标注**(或专业标注团队): 将松散 ROI 改为设备级紧框 + 补全同图漏标。估算: 16 类 6218 框, 熟练标注员约 2-3 人周。这是所有实验一致指向的瓶颈, 也是 mAP50 0.09→0.40 量级提升的唯一已知路径。
